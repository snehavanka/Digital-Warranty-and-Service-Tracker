# Digital Warranty & Service Tracker

A full-stack web application designed to help users efficiently manage product warranties, service records, and warranty documents. The application provides a secure and user-friendly platform to organize warranty information, upload warranty cards, track service history, and manage user profiles.

---

## 📖 Overview

Digital Warranty & Service Tracker simplifies warranty management by allowing users to store product information, maintain warranty documents, monitor warranty status, and record service history in one place. The application offers an intuitive interface and secure authentication to provide a seamless user experience.

---

## ✨ Features

* 🔐 Secure User Authentication
* 📊 Dashboard with Warranty Overview
* 👤 Profile Management
* 📦 Product Management
* 🛡️ Warranty Management

## 🚀 Getting Started

### Prerequisites

* Java 17 or later
* Node.js
* npm
* PostgreSQL
* Maven

### Clone the Repository

```bash
git clone https://github.com/snehavanka/Digital-Warranty-and-Service-Tracker.git
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

### Backend Setup

```bash
mvn spring-boot:run
```
